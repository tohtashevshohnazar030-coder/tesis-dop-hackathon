# TESIS — Product Context

## Target users
- Farmers in Uzbekistan (initial focus: Surxondaryo region)

## User input (MVP)
- Crop type
- Location (region or lat/lon)
- Soil moisture level (manual)

## Output (MVP)
- Irrigate: YES/NO
- Water amount (liters)
- Duration (minutes)
- Confidence score
- Factor breakdown (soil / temperature / rain)
- Plain-language explanation

## Non-goals (MVP)
- No hardware
- No IoT
- No “AI decides irrigation”
